# Security and disclosure

This repository is designed to contain source code, fixture tests and screenshots—not private research records or credentials.

If a credential or restricted research abstract has ever been committed, **treat it as exposed**. Remove it from the branch, rotate the credential, and review/rewrite history as appropriate; adding `.gitignore` alone will not erase historical commits.

The API is **local-only** pending publication-rights review. Do not expose `/api/research/search` on a public server until abstract redistribution permissions and production controls are in place.

For security concerns, contact the repository owner privately rather than opening a public issue containing credentials or proprietary data.
